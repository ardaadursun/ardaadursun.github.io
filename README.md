# Portfolio

Persönliche Portfolio-Website – reines HTML, CSS und JavaScript, kein Build nötig.

## Ansehen

`index.html` im Browser öffnen, oder lokal starten:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## Inhalte bearbeiten

| Was                         | Wo            |
|-----------------------------|---------------|
| Skills, Projekte, Werdegang | `data.js`     |
| Über-mich-Text, Name, Links | `index.html` (nach `[` und `DEIN-` suchen) |
| Farben, Layout              | `style.css` (oben bei `:root`) |

Neues Projekt hinzufügen = einen Eintrag in `PROJECTS` in `data.js` ergänzen.

## Veröffentlichen (kostenlos)

GitHub-Repo erstellen, pushen, dann unter *Settings → Pages* den `main`-Branch auswählen.

Live: https://ardaadursun.github.io
